# Daniel Florez Thomas

### Economía · Analítica de datos · IA aplicada

Soy economista y magíster en Inteligencia Analítica de Datos de la Universidad de los Andes. Desarrollo análisis, modelos predictivos y productos de información para apoyar decisiones económicas, financieras y humanitarias.

Mi trabajo combina **Python, SQL y Power BI** con validación de datos, documentación metodológica y comunicación de resultados.

- **Analítica y modelos:** series de tiempo, pronósticos y Machine Learning.
- **Datos y automatización:** integración de fuentes, procesos ETL y flujos reproducibles.
- **Business Intelligence:** indicadores, tableros y visualizaciones para explorar resultados.
- **IA aplicada:** apoyo al análisis y la automatización, con revisión técnica.
